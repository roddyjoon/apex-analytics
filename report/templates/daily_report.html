Methodology

Win probabilities use a four-layer ensemble:
Monte Carlo simulation (7,000 iterations, Statcast inputs, bottom-up PA model) · Team Elo ratings (dynamic, post-game updated) · Random Forest (15-feature non-linear model, 2023–2024 training) · Logistic Regression (12-feature interpretable baseline)

Final output is calibrated via {% if calibration_method == 'isotonic' %}isotonic regression{% else %}Platt scaling{% endif %} on {{ calibration_n_games }} historical games. Confidence intervals reflect ensemble variance across all four layers.
